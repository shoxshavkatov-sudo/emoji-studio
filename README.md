# GRID Emoji Studio

Мини-сайт для создания анимированных эмодзи под своё название: вводишь слово
(латиница или кириллица), выбираешь цвет, обводку и размер — видишь живые
превью и скачиваешь готовые `.tgs`-файлы для Telegram.

## Как пользоваться

1. Открой сайт, введи своё название (до 12 символов, A–Z, 0–9, А–Я).
2. Подбери цвет текста, обводку и размер ползунком.
3. Жми «Скачать .tgs» под понравившимся превью.
4. В Telegram: [@Stickers](https://t.me/Stickers) → `/newemojiset` → отправь
   файл → привяжи к эмодзи. Лимит файла — 64 КБ (сайт предупредит, если больше).

## Деплой на Render

Репозиторий содержит `render.yaml` (Render Blueprint). Два способа:

- Кнопка: [Deploy to Render](https://render.com/deploy?repoURL=https://github.com/shoxshavkatov-sudo/emoji-studio)
- Вручную: Render → New → Blueprint → выбери этот репозиторий.

Статика без сборки: `runtime: static`, корень публикуется как есть.

## Устройство

- `index.html` — интерфейс (превью на lottie-player, скачивание через pako.gzip).
- `engine.js` — движок: блочный шрифт 4×5 (латиница + кириллица), генераторы
  собственных шаблонов и замена текста в слотах сторонних шаблонов
  (матричный обход вложенных трансформов, автоповорот в вертикальных слотах).
- `templates.js` — база шаблонов (66 анимаций).
